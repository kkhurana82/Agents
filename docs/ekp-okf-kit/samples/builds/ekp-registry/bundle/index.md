# EKP anchor registry

## Capability

* [Seat eligibility](/anchors/capability/seat-eligibility.md) - Deciding which passengers may occupy which seats.

## Component

* [Check-in](/anchors/component/dcs.checkin.md) - Passenger check-in flow, including document and eligibility checks.
* [Seat Assignment](/anchors/component/dcs.seat-assignment.md) - Allocates and changes seats, applying seat eligibility rules.

## Domain

* [Departure Control](/anchors/domain/departure-control.md) - Check-in, seating, boarding and flight close for departing flights.

## System

* [Departure Control System](/anchors/system/dcs.md) - The system that runs check-in, seat assignment and boarding.

## Term

* [Exit row](/anchors/term/exit-row.md) - A seat row adjacent to an emergency exit, with occupant restrictions.
* [Infant](/anchors/term/infant.md) - A passenger under 2 years travelling on an adult's lap (INF).
