# When to use

A passenger travelling with a lap infant sees `INF EXIT` at the self-service kiosk after trying to move to an exit-row seat.[^page]

# Steps

1. Explain that passengers with an infant cannot sit in an exit row.
2. Offer a non-exit seat in the same cabin from the seat map.
3. If the passenger says the infant was removed, check the booking first; the seat map re-runs the check when the infant count changes.

[^page]: DCSOPS page 48219911, version 3
