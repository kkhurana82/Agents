# BRD: BRD-SEAT

## Business Rule

* [Exit-row seat rejected when passenger has an infant (as stated in BR-SEAT-014)](/rules/BRD-SEAT/BR-SEAT-014/eligibility-3ade07.md) - Business rule extracted from BR-SEAT-014: reject an exit-row seat if the passenger travels with an infant.

## Requirement

* [BR-SEAT-014: no exit-row seat for a passenger travelling with an infant](/requirements/BRD-SEAT/BR-SEAT-014.md) - The system shall not assign a seat in an exit row to a passenger travelling with an infant.
